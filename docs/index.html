How this dashboard works

1. What runs where

This page is a fully static site — HTML, CSS and JavaScript, hosted on GitHub Pages. There is no server component: when you choose a CSV file, it is read and parsed entirely inside this browser tab (via the File API + PapaParse) and never transmitted anywhere. Charts are drawn with Plotly.js.

2. Core flow

  1. Load CSV (file picker or the bundled sample file).
  2. Detect key columns (date/time/source/tickets/ticket type/postcode/session).
  3. Prepare standardized records (js/analytics.js: prepareData).
  4. Build chart-specific aggregated series (getSourceSeries, getTicketTypeSeries, getPostcodeSeries, getSessionTicketTypeBreakdown).
  5. Render charts and tables, re-running on any filter/control change (js/app.js).

3. Notes on "Other" responses

Responses starting with "Other" are shown as their own series where possible. Anything containing "BO", "bo", "season ticket(s)" or "life member(s)" is grouped into a single "Box Office" series; everything else starting with "Other" is grouped into a generic "Other" series. The detailed breakdown (each individual "Other: ..." value) is still available in the Other Responses table above.
